## Overview

Vitality Mod introduces a blood magic theme to Terraria with a complete new content tier — 150+ items centered around soul extraction, blood-powered weapons, and dark ritual mechanics, a new boss that serves as an early-hardmode challenge, and a companion summoning system that binds defeated boss spirits as permanent combat companions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Vitality Mod** delivers the features you need in a clean, intuitive package.
